تحديث Cloudflare مطلوب قبل استخدام زر المتابعة
================================================

1. فك ضغط الحزمة وابحث عن worker.js.
2. افتح مستودع GitHub Hitham على الفرع main.
3. استبدل worker.js الموجود في جذر المستودع بالملف المرفق، ثم اضغط Commit changes إلى main.
4. انتظر حتى يكتمل Cloudflare Deployment باللون الأخضر. لا تغيّر wrangler.jsonc أو اسم Worker أو إعداد Durable Object.
5. بعد نجاح النشر، ثبّت APK 4.2.0+504 على الهاتفين.

بعد انتهاء مباراة، يضغط كل لاعب «متابعة مع نفس المنافس». عندما يوافق الطرفان تبدأ مباراة جديدة تلقائيًا في الغرفة نفسها، وتُصفّر النقاط، ولا يُعاد إرسال كود الدعوة. إذا اختار أحدهما «منافس جديد»، يعود إلى شاشة البداية لإنشاء غرفة جديدة أو إدخال كود جديد.

إذا ثبتّ التطبيق قبل تحديث Worker، ستظل المنافسة المعتادة تعمل، لكن زر المتابعة لن يعمل حتى ينجح النشر الجديد.
