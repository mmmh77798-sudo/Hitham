# لغز هيثم — الإصدار 4.3.0+505

لعبة أندرويد عربية RTL تضم ٥٠٠ سؤال معلومات عامة، بأربعة خيارات وشرح للمعلومة بعد الإجابة.

## أنماط اللعب
- **اللعب الفردي:** تحدٍ فردي محلي عبر الأسئلة الموجودة في التطبيق.
- **منافسة العباقرة 1 ضد 1:** غرفة برمز دعوة، مؤقت، نتيجة، إعادة مباراة، وإعلان اسم الفائز.
- **فريق العباقرة:** فريق أحمر وفريق أزرق في غرفة واحدة ورمز واحد. كل فريق من لاعب واحد حتى ١٠ لاعبين، ويسمح باختلاف العدد. تظهر الأسئلة للفريقين، وتُحتسب أول إجابة من كل فريق عن السؤال.

> يحتاج نمط الفريق إلى نشر `worker.js` المرفق على Cloudflare قبل استخدامه. راجع `TEAM_MODE_INSTRUCTIONS_AR.txt`.

## ملفات مهمة
| الملف | المحتوى |
|---|---|
| `lib/main.dart` | الواجهة الرئيسية والأسئلة الفردية |
| `lib/duel.dart` | شاشة قسم العباقرة وإبقاء المنافسة الفردية |
| `lib/team_duel.dart` | شاشة إنشاء غرف الفريقين والانضمام واللعب |
| `worker.js` | واجهة API وغرف المنافسة الفردية والجماعية |
| `questions.json` | بنك الأسئلة لخادم Cloudflare |
| `TEAM_MODE_INSTRUCTIONS_AR.txt` | خطوات نشر الخادم وطريقة اللعب |
| `release_4_3_0_505.apk` | APK arm64-v8a الجاهز للتثبيت |
