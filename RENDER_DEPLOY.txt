# قسم العباقرة — رفع الخادم إلى Render

هذه نسخة مسطّحة: ارفع جميع الملفات في هذا المجلد إلى جذر مستودع GitHub نفسه، بجانب README.md و RENDER_DEPLOY.txt الموجودين لديك. ملف render.yaml هنا مُعدّ للعمل من جذر المستودع، ولا يحتاج مجلد server/.

في GitHub افتح المستودع ثم Add file (+) → Upload files، وحدد الملفات المفكوكة هنا. اسمح باستبدال render.yaml القديم. ثم Commit changes. بعد ذلك في Render: New → Blueprint → اختر المستودع → Apply.

اختبر بعد اكتمال النشر: https://اسم-الخدمة.onrender.com/api/health
النتيجة يجب أن تتضمن ok=true و questions=500. أرسل لي اسم النطاق العام فقط لأبنيه افتراضيًا في APK.

الخطة free للتجربة: عنوان ثابت لكنه ينام بعد ١٥ دقيقة بلا طلبات، وقد تُفقد الغرف عند إعادة التشغيل. ليست تشغيل ٢٤/٧.
